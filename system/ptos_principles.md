# PTOS v2 — Core Principles

## 1. Plain Text First
All data must be human-readable plain text.

## 2. Separation of Layers
Journal → Meaning
Tasks → Responsibility
Records → Reality
Notes → Knowledge

## 3. Append-Only Ledger
Records are never edited. Corrections are new entries.

## 4. One Event Per Line
Each record line represents one fact.

## 5. Predictable Grammar
Structured fields use key:value format.
Values contain no spaces.
Use lowercase and underscore.

## 6. Minimal Necessary Fields
Track only what is reviewed.
