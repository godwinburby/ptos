What are routines?

Routines are your daily recurring tasks — things you do every day that would clutter your main todo list. This page shows them as checkbox cards grouped by context (e.g. morning, evening); the day view is a timeline whose colors follow each routine's project.

How to add a routine

Go to the Todo page and add a todo with:

  • +routine — the project tag that identifies it as a routine
  • @morning (or any context) — becomes the card group on this page
  • rec:1d — daily recurrence so it auto-regenerates after completion
  • due:today — due date for today
  • due_time:09:00 — start time for the day view timeline
(A) Check mail +routine @morning due:today due_time:09:00 rec:1d
How it works
  • Check items off here — they complete and auto-regenerate for tomorrow
  • Click an item's text to edit it
  • Use the "+ Add" button on each card to quickly add a routine to that context
  • Switch to Day view to see your routine as a timeline with time blocks
  • Each @context becomes a separate card; colors follow the project (e.g. +gym) in both cards and the day view
