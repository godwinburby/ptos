Set up sync between two devices (one-time)
  1. Install and start Syncthing on each device that should share the data (this one included). Open its UI at http://127.0.0.1:8384, go to Actions → Show ID, and copy each device's ID.
  2. On the first device's Syncthing UI, click Add Remote Device and paste the other device's ID. On the other device, do the same with the first device's ID. Pairing is mutual: both devices must have each other.
  3. On the device that holds the ptos-data folder, click Add Folder. Set Folder ID to {% if syncthing_status.folder %}{{ syncthing_status.folder.id }}{% else %}ptos-data{% endif %} (it must match on both devices), path to {{ base_dir }}, and under Sharing add the paired device with Send & Receive.
  4. On the other device, accept the incoming folder and set its path to that device's own ptos-data directory (e.g. ~/storage/shared/ptos-data on Android — the paths may differ per device; the folder ID is what syncs, not the path).
  5. Press Refresh here — you should see both devices connected and the folder at 100%.
Stuck on "0 of 1 other device connected"? Check both IDs were exchanged in both directions and that the devices can reach each other (same Wi‑Fi, or open the firewall/relay on Syncthing's Settings tab). This card only observes Syncthing — PTOS never syncs anything itself.
